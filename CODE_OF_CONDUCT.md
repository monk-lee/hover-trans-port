# Code of Conduct

## Our Pledge

We aim to make this project a respectful, practical, and technically focused space.

## Expected Behavior

- Be respectful and direct.
- Focus criticism on code, design, documentation, and user impact.
- Assume contributors may have different operating systems, locales, and accessibility needs.
- Keep discussions relevant to the project.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing private information.
- Sustained off-topic disruption.
- Dismissing privacy or security concerns without technical reasoning.

## Reporting

Report code of conduct concerns through the repository maintainers. If the report includes private information, sensitive context, or a maintainer conflict of interest, use GitHub private vulnerability reporting so the report is not published as a public issue.

Reports involving a maintainer should be handled by a maintainer who is not involved in the reported conduct. If no uninvolved maintainer is available, the project should bring in a trusted outside reviewer before taking enforcement action.

## Enforcement

Maintainers may edit, hide, or remove comments and may block contributors who repeatedly violate this code of conduct.
